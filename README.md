# Uraan - Global Education & Scholarship Platform

Uraan is a modern, student-centric study-abroad and scholarship platform designed to empower international students (especially from Bangladesh and developing nations) to discover global scholarship opportunities, evaluate country eligibility, and access affordable application and document preparation services.

---

## ✨ Features

- 🎓 **Smart Scholarship Discovery**: Comprehensive directory of government and university scholarships (DAAD, Chevening, MEXT, CSC, Turkiye Burslari, Stipendium Hungaricum, Erasmus Mundus, etc.) with real-time category, country, and award filters.
- 🌍 **Continents & Country Guides**: Interactive marquee exploration of continents with detailed breakdowns of admission requirements, tuition benefits, and living cost estimates.
- 🏷️ **Dedicated Plans & Pricing**: Affordable country application support packages (UK, Germany, USA, Canada, Australia, Italy, Finland) and multi-country passes.
- 🛠️ **Dedicated Standalone Services**: Individual document drafting and review services (SOP, LOR, CV makeover, cold email packs, mock visa prep) with fast turnarounds.
- 💬 **Direct WhatsApp Community**: Community access to peer applicants, verified counselors, and regular admission updates.
- 📱 **Responsive UI/UX**: Built with a modern aesthetic, custom video hero showcase, smooth animations, and yellow/red button styling.

---

## 🚀 Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Modern Vanilla CSS with responsive design & fluid animations
- **Linter**: Oxlint
- **Icons**: Emoji & Custom SVG Assets

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
git clone https://github.com/MDABUTALHA-11/Urann.git
cd Urann
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
